
# Typing Speed Challenge

A beginner-friendly typing speed testing
application built using Django and PostgreSQL.

## Technologies

- Python 3.12
- Django 5.2
- Docker
- PostgreSQL 17
- HTML, CSS, JavaScript
- Bootstrap 5.3

## Features

- Typing speed test
- WPM calculation
- Accuracy calculation
- User authentication
- Leaderboard
- Performance history

## Run the project

docker compose up --build
